PhishGuard project for csf 2

This is a small phishing detection website made for my Csf project.

~ You can paste a website URL into it and it checks the URL and shows its risk level..(moderate, critical or normal)
which can help identify suspicious or phishing websites.

~Made using Python, HTML, CSS and JScript.

~To run it, install the required packages using:

pip install -r requirements.txt

Then run:

python app.py

The terminal will give you the local website link. Open it in your browser and paste a URL you wanna scan to scan it (there are txt file with some sus websites included in the project folder for testing purpose)
